# Accents FR

Ajoute à une police (.ttf / .otf) toutes les lettres accentuées latines qui lui manquent, et la ponctuation typographique, dans le style de la police.

Utiliser l'outil : https://farouzlevi-spec.github.io/accents-fr/

La police est traitée dans le navigateur, elle n'est envoyée nulle part.
En ligne de commande : `python3 accents_fr.py MaPolice.ttf` (nécessite `pip install fonttools`).
